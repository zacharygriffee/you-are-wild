# FightFuckFeed Repository Guide

This repository currently keeps the tactical rewrite as the canonical maintained app and preserves the original monolithic game as legacy reference.

## What To Edit

- `FightFuckFeed.tactical/src/`: source JavaScript modules for the tactical app.
- `FightFuckFeed.tactical/template.html`: source HTML and CSS shell for the tactical app.
- `FightFuckFeed.tactical/build.js`: build and validation script.
- `FightFuckFeed.tactical/test/`: repository tests.

## What Not To Hand-Edit

- `dist/FightFuckFeed.tactical.html`: generated by `npm run build`.
- `legacy/FightFuckFeed.me.html`: preserved legacy monolithic app.
- `archive/`: historical experiments, old patches, and stale planning docs.

## Commands

Run commands from `FightFuckFeed.tactical/`:

```sh
npm run build
npm test
npm run test:core
npm run test:ui
npm run lint
npm run check
npm run full-build
```

From the repository root, the same verification is available with:

```sh
npm run full-build
```

## Development

```sh
cd FightFuckFeed.tactical
npm run dev
```

The dev command starts the build watcher and serves the repository at `http://localhost:3000`.

## Release Output

The distributable single-file tactical build is:

```text
dist/FightFuckFeed.tactical.html
```

If source changes, regenerate that file with `npm run build` and verify it with `npm run check`.
