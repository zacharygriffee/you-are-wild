# You Are Wild 0.11.0 — Public Preview

Released 2026-07-16.

## Added

- Offline player-facing release notes and a once-per-version update notice.
- Activity Log access before starting a game and from system screens.
- OpenAI-compatible reasoning-effort controls.

## Changed

- Host Catalog appears only when the server supplies a real catalog.
- Remote provider attempts from `file://` require an explicit session-only
  advanced override.

## Fixed

- Development example and sample-module controls are no longer public Mod
  Manager features.
- Provider, host-catalog, and narration errors remain visible in the Activity
  Log before a run starts.

## Known Issues

- Browser-direct AI connections require compatible TLS and CORS behavior.
- Providers may reject reasoning-effort values unsupported by the selected
  model.

## Compatibility

Existing 0.10.x saves load automatically. Modules requiring game version
0.10.0 remain compatible unless their own manifest declares stricter
requirements.
