# You Are Wild 0.11.1 — Stabilization

Prepared 2026-07-17.

## Added

- Expanded automated keyboard, focus, localization, and responsive-device
  coverage for system and provider surfaces.

## Changed

- New OpenAI-compatible profiles default to an 8,192-token completion ceiling.
  High reasoning may still need 16,384 or more.

## Fixed

- Reasoning-capable models have substantially more default room to emit visible
  narration after using hidden reasoning tokens.

## Known Issues

- Browser-direct AI connections still require compatible endpoint TLS and CORS
  behavior.
- Individual providers can enforce a lower model-specific output maximum.

## Compatibility

Existing saves and modules remain compatible. Existing provider profiles retain
their stored completion-token ceiling; edit a profile to adopt the new default.
