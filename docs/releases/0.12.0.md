# You Are Wild 0.12.0 — Traversal and Group Play

Version 0.12.0 is the first public preview with the moddable Tileset Pack V1
renderer, refined traversal presentation, and trained multi-target fighting.

## Highlights

- Textured terrain now composes biome, road, shoreline, interior, landmark,
  resource, danger, and presence layers while retaining semantic emoji fallback.
- Hosted play offers Textured and Lightweight choices backed by the same game
  runtime. Textures are separate cacheable files; Lightweight avoids their
  initial transfer. The downloadable HTML remains fully self-contained.
- One-to-many and many-to-many Fight effects are distributed per actor. Units
  progress from Novice through Master, while authored equipment, instincts,
  and area techniques can extend the model.
- Group interaction cancellation, mobile belt swiping, scoped startup
  readiness, survival balance, fleeing, containment outcomes, roads, beaches,
  caves, and building interiors received compatibility-preserving fixes.

## Compatibility

Existing 0.10.x and 0.11.x saves load automatically. Multi-target practice is
new additive metadata, so units from older saves begin at Novice. Existing
modules retain compatibility; the save schema remains 11 and the module API
remains 1.

## Known issues

- Browser-direct AI providers still depend on endpoint TLS and CORS support.
- Combat and survival values remain alpha balance and will continue to change.
- The Textured hosted mode transfers approximately 4 MB on its first visit.
