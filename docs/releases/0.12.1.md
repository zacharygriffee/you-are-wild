# You Are Wild 0.12.1 — Recovery and Party Interaction

Version 0.12.1 is a compatible public-preview patch focused on defeat recovery,
party interaction reliability, and responsive presentation.

## Added

- Regular defeat recovery can leave a persistent recovery bag or retain carried
  inventory according to the selected setting.
- Settings includes a guarded Test Player Death command for exercising the real
  recovery path.
- Companions can be dropped off and later rejoin without duplicate recruitment
  rewards. Survivors of a player defeat remain at the settled battle location.

## Changed

- Player death no longer cancels an encounter while companions remain able to
  act. Recovery becomes available after the battle reaches a real outcome.
- Party-side interactions are not blocked by opposing-formation row rules.
  Combat planning can combine companion and enemy targets.

## Fixed

- Healing items restore the selected living party member, consume one item,
  and spend the correct combat turn.
- Group cancellation, companion targeting, recovery controls, and desktop stage
  sizing remain stable under the covered combat and responsive flows.
- Recovery bags created inside structures remain in the exact interior room and
  persist through the structure's world-state record.

## Compatibility

- Existing 0.10.x, 0.11.x, and 0.12.0 saves load without migration work by the
  player. New defeat, recovery-bag, and companion-placement fields are additive.
- Existing modules remain compatible. First-party package metadata is stamped
  with 0.12.1 while minimum compatible versions remain unchanged.

## Known Issues

- Browser-direct AI connections still depend on endpoint TLS and CORS support.
- Combat, survival, and longer-save defeat recovery remain active alpha
  playtest areas.
- Textured mode transfers the bundled atlas media on first use; Lightweight
  mode avoids that transfer.
