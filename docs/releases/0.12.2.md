# You Are Wild 0.12.2 — Feed and Retreat Reliability

Version 0.12.2 is a compatible public-preview patch focused on explicit Feed
direction, living retreat outcomes, and interaction-flow regression coverage.

## Added

- Feed offers contextual Tend, Nurse, Offer Self, and Offer Piece variants after
  the actor and target are known.
- Living player and companion retreats relocate to a safe adjacent tile instead
  of entering death recovery. A retreat remains in combat when no safe route is
  available.

## Changed

- Feed consistently treats the selected actor as the source and the selected
  target as the recipient or consumer.
- Legacy inverse-direction Feed identifiers remain callable for old saves and
  trusted modules but are hidden from the core picker.

## Fixed

- Combat Feed confirmation remains reachable on desktop and mobile and cannot
  silently redirect a companion action to the player.
- Mobile traversal clearance and touch-target coverage protect the 3x3 map and
  command surfaces from clipping.
- Overlay focus restoration, localized save/module metadata, and combat-plan
  reload recovery have dedicated regression coverage.

## Compatibility

- Existing 0.10.x through 0.12.1 saves load without migration work by the
  player. This patch does not change the save schema or module API.
- Existing module minimum-version contracts remain valid. First-party package
  production metadata is stamped with 0.12.2.

## Known Issues

- Browser-direct AI connections still depend on endpoint TLS and CORS support.
- Combat balance, survival pacing, and longer-save defeat recovery remain active
  alpha playtest areas.
- The broader mobile flow for switching party/enemy context and keeping
  structure actions visible is deferred to a dedicated interaction redesign.
- Textured mode transfers the bundled atlas media on first use; Lightweight
  mode avoids that transfer.
