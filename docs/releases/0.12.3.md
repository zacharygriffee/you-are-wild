# You Are Wild 0.12.3 — Shared Subinteractions and Module Doctrine

Version 0.12.3 is a compatible public-preview patch focused on consistent
combat interaction presentation and accurate guidance for module authors.

## Added

- Combat Feed and Feast now open the same focused variant sheet used by
  exploration on desktop and mobile.
- The canonical Module Doctrine documents the supported package envelope,
  permissions, asynchronous settings, content posture, host policy, and
  executable extension seams.

## Changed

- Combat variant selection preserves the selected actor and target while the
  sheet is open.
- Back and Escape cancel the sheet without spending the turn or leaving the
  composer in a stranded phase.
- Obsolete narration-agent guidance has been removed in favor of the doctrine
  and focused maintained references.

## Fixed

- Feed and Feast variants no longer render as a narrow inline combat column
  that can be clipped by the stage.
- Desktop and mobile combat now share one accessible focus, selection,
  cancellation, and cleanup contract for subinteractions.
- Module documentation no longer describes arbitrary locale keys as runtime
  hooks or asynchronous setting reads as synchronous values.

## Compatibility

- Existing 0.10.x through 0.12.2 saves load without migration.
- The save schema and module API remain unchanged.
- Existing module minimum-version declarations remain valid.
