# You Are Wild 0.13.0 — Exchange-Specific Narration Ownership

Version 0.13.0 is a compatible public-preview minor release that lets optional
narrators claim only the closed Scene Beat exchanges they understand.

## Added

- Narration orchestrators may declare `claimsExchange(envelope)` separately
  from their module-wide `isActive(policy)` readiness gate.
- Claim predicates receive a bounded, deeply frozen copy of the canonical
  closed-exchange envelope.
- Declined or failed claims fall through deterministically to eligible
  lower-priority narrators.

## Fixed

- Caller-supplied envelopes cannot seed, replace, or otherwise alter canonical
  ownership before or after an exchange closes.
- Non-function ownership predicates are rejected during registration rather
  than silently becoming claim-all predicates.

## Compatibility

- Existing 0.10.x through 0.12.3 saves load without migration.
- Existing orchestrators that omit `claimsExchange` keep their previous
  claim-all behavior.
- Modules using `claimsExchange` require game version 0.13.0 or newer.
