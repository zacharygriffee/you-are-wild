# You Are Wild 0.14.0

Released 2026-07-21 as an alpha public preview.

## Added

- Species Profile V1: a validated boundary for species-authored starting stats,
  size, difficulty, body parts, existing abilities, temperament, canon, and
  encounter placement.
- Elemental Species 0.2.0 with Emberkin, Tidekin, and Stonekin.
- Sites supplies Elemental Species as an optional host package. It is installed
  for discovery but remains disabled until the player enables it.

## Changed

- Character creation refreshes its species choices immediately after module
  load or unload.
- A valid current selection is preserved; an unavailable mod species falls back
  safely to Human.
- Player creation and normalization apply only validated profile fields.

## Fixed

- Enabled species packages appear without a page reload.
- Disabled packages remove their owned species and encounter entries.
- Unsupported profile mechanics are rejected instead of entering runtime state.

## Compatibility

Existing 0.10.x through 0.13.0 saves load without migration. Existing species
mods remain compatible when they omit `profile`; Species Profile V1 requires
game version 0.14.0 or newer.

Elemental traits remain descriptive in this release. Elemental damage and
resistance require a future executable mechanic seam.
