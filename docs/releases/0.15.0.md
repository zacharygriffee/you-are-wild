# You Are Wild 0.15.0

Status: **draft — not published**

Channel: **development candidate for public preview**

Release date: **operator-gated**

This record describes the current 0.15.0 candidate. It must be reconciled with
the exact generated artifact and observed CI result before publication.

## Added

- Mobile Interaction Flow V2: one state-aware mobile Roster with a persistent
  actor-target-intent composer.
- Visible bounded Hungry and Starving pressure for players, companions, and
  creatures.
- Generator V4 safe-start and opening-admission semantics, retained through
  the current Generator V6 road raster.
- Deterministic ambush awareness using Wisdom, visibility, terrain,
  darkvision, Scout, Guard, and enemy temperament.
- Declarative UI Contribution, Locale Pack, Sprite Pack, Combat Technique,
  Resource Ledger, and Recovery Mode V1 foundations.
- Optional Waystone Recovery and Elemental Species host packages.

## Changed

- New worlds use Generator V6: the connected route hierarchy is painted as
  one-tile orthogonal roads with at most two road-served POIs per region.
- Ordinary opening encounters use distance pressure, tier/group caps, and a
  weakest-party threat estimate instead of hidden damage reduction.
- Roads reduce encounter pressure relative to surrounding wilderness.
- Mobile and desktop share the same selection grammar, contextual
  subinteraction menus, and target-confirmation behavior.
- The generated artifact remains offline-capable while hosted presentation
  assets use immutable cacheable resources.

## Fixed

- Hostile encounter lifecycle no longer leaves a living hostile outside combat
  or turns a living retreat into death recovery.
- Death/Defeat V3 settles companion-led combat before player recovery and
  preserves stranded survivors, recovery bags, and exact interior placement.
- Multi-party and multi-target interactions retain their selections, costs,
  reach failures, and save/load state.
- Novice one-to-many social interactions now resolve as real attempts instead
  of presenting a valid command that an obsolete aggregate-stat gate silently
  rejects; Fight remains the only interaction with distributed-effect mastery.
- Party cards refresh immediately after travel Hunger changes rather than
  remaining visually stale until a reload.
- Player and enemy Flee outcomes publish localized prose to the Scene feed
  rather than exposing internal result tokens.
- Generic narrative failures use player-aware and third-person grammar.
- Road rasterization no longer creates dense false T-junction meshes from one
  diagonal macro segment.
- Responsive interaction, focus, localization, long-text, and horizontal
  overflow regressions are covered by the maintained viewport matrix.

## Ghost disposition

The accepted candidate baseline is the conservative built-in opt-in Ghost
pilgrimage documented in `../ghost-recovery-prepublish-decision.md`:

- selected in Settings before defeat;
- begins at the defeat site after ordinary companion settlement;
- uses the configured inventory consequence once;
- permits traversal and read-only history only;
- suppresses living-world encounters and actions with explicit feedback;
- resurrects freely at the validated home/safe place with 1% condition.

No shrine economy, spectral abilities, altered companion outcome, or defeat
prompt is authorized for 0.15.0.

## Compatibility

Local exact-candidate compatibility evidence:

- Save schema remains `11`; current 0.10.x through 0.14.0 saves are expected to
  load through maintained migrations.
- Module API remains `1`; existing minimum-version declarations remain valid.
- Recorded generator versions remain immutable. Existing V4/V5 maps are not
  converted to V6.
- Additive V1 module contracts require their documented minimum game versions;
  no existing permission or public slot is removed.
- A representative binary save produced by the published 0.14.0 serializer
  loads through the maintained 0.15.0 slot path.
- First-party host packages are synchronized from their maintained sources;
  build and Sites render gates reject stale catalog, package-version, or
  `gameVersion` mirrors.

## Known alpha areas

- Combat and survival tuning still requires long-form play after publication.
- Ghost is conservative and traversal-only by design.
- Physical-device mobile comfort and subjective authored-art/translation
  quality remain operator review.
- Browser-direct AI narration depends on endpoint TLS, CORS, response shape,
  token budget, and timeout behavior.
- The first Textured visit downloads atlas media; Lightweight avoids that
  transfer.
