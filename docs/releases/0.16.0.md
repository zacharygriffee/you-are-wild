# You Are Wild 0.16.0

Status: **approved select-group alpha**

Channel: **alpha — select playtest group**

Release date: **2026-07-26**

This record describes the approved 0.16.0 Core Game Maturity alpha. It is
intended for a select playtest group rather than general public distribution.
Beta and general-public promotion remain separate operator decisions.

## Added

- Item Registry V2 with stable core/module identities, bounded stacks and
  capacity, healing effects, quest-item protection, and coherent acquisition.
- Quest Contract V2 with six lifecycle states, physical turn-in policies,
  deterministic procedural archetypes, bounded authored stages, and guarded
  rewards.
- Quest World Directives V1 with deterministic required creature/item
  placement, scoped encounter/search weight boosts, map guidance, lifecycle
  cleanup, and the same bounded data-only contract for module quests.
- Review Map V2 with independently filterable planning layers, tracked quest
  guidance, known-route directions, tile inspection, zoom, pan, recenter,
  desktop docking, and a mobile sheet.
- Companion Behavior V2 with separate Duty, Stance, and Control, deterministic
  autonomy, recruitment continuity, and optional provider-assisted decisions.
- Progression V2 with controlled XP sources, practice boundaries, versioned
  perk effects, deterministic eligibility, anti-farming guards, and modular
  perk profiles.
- A visible-only Perk Frontier that presents only choices currently available.
- Progressive Tutorial V2 with replayable state-derived lessons,
  point-of-choice explanations, and optional strategy tips.

## Changed

- Procedural quests return to their original giver by default and provide
  direction, distance, next-step, and known-route guidance.
- Mandatory Hunt objectives reserve sparse quest-bound targets instead of
  depending on ambient biome luck. Gather objectives may temporarily boost the
  requested registered item near their marked search area.
- Every shipped core item has an implemented use or an honest trade, quest, or
  key purpose. Craftability metadata remains internal until a crafting system
  exists.
- Companion roles and orders migrate into separate Duty, Stance, and Control
  records. Legacy fields remain compatibility mirrors.
- Manual, deterministic, and provider-assisted companion commands share one
  legal validator and outcome resolver. Provider failure falls back without
  losing the turn.
- The normal perk surface hides locked, selected, incompatible, and
  hypothetical future nodes. Confirmed respec remains free during alpha.
- Chew is a progressive Feast-based attack. Its damage reduces Vitality and
  condition equally; exploration survivors flee to an adjacent valid tile or
  become hostile and enter combat.

## Fixed

- Legacy item names, saved perks, quest state, tracked objectives, and
  companion behavior normalize without discarding supported state.
- Missing or disabled module providers remain inert and recover their owned
  item/perk definitions when safely re-enabled.
- Containment, release, recruitment, drop-off, defeat, and save/load no longer
  duplicate quest services, rewards, or recruitment behavior seeds.
- Generic Defeat objectives credit a hostile once when the player or an
  autonomous companion slays, subdues, or contains it. Fleeing, unrelated
  actors, and release/re-containment cycles do not award progress.
- Review Map controls do not materialize unrelated unknown world state.
- Tutorial focus, active-state contrast, touch sizing, enlarged text, high
  contrast, reduced motion, and long Spanish copy pass the viewport matrix.

## Compatibility

- Save Schema remains `11`. Existing 0.10.x through 0.15.0 saves load through
  maintained additive adapters.
- Module API remains `1`. Existing minimum-version declarations remain valid.
- Modules using Item Definition V2 or Perk Profile V1 should require game
  version 0.16.0 or newer.
- Recorded generator versions and existing world topology remain unchanged.

## Known issues and deliberate exclusions

- Long-form external and physical-phone playtesting remains necessary for
  balance, pacing, clarity, and enjoyment.
- Crafting, evolving companion emotions, new difficulty profiles, arbitrary
  module callbacks, and richer recovery economies remain deferred.
- Provider-backed companion control and AI narration remain optional.
  Deterministic play does not depend on either provider.
- Human translation quality and authored-art review remain operator work.
