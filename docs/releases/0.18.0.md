# You Are Wild 0.18.0

Status: **candidate — not published**

Channel: **alpha — select playtest group**

Release date: **operator-gated**

This record describes the bounded Moddable Core V1 candidate. It is intended
for a select playtest group rather than general public distribution. Commerce,
public-preview promotion, and hosted publication remain separate decisions.

## Added

- Moddable Core V1 owned registries for data-only actions, statuses,
  restraints, equipment, body mass, biome recipes, and audio packs.
- Action Resolver V1 with deterministic availability, semantic structure
  requirements, costs, contests, effects, and immutable post-commit outcomes.
- Core Grab, Pull, and Escape actions over explicit source-target restraint
  relationships.
- Appetite-gated Seduce using Spirit against Wisdom. Success makes the target
  recruitment-ready and withdraws both participants without bypassing party
  capacity.
- Equipment Definition V1 as a bounded component separate from ordinary item
  identity.
- Body Mass Ledger V1 with size-derived mass, allowed pieces, regrowth,
  corpse conversion, and consumption conservation.
- Biome Recipe V1 for deterministic boundary and procedural classification of
  matching unmaterialized tiles.
- World Scaling V1 across distance, biome, cave, structure, and authored
  difficulty for encounters and procedural quest rewards.
- Encounter Outcome V1 and public frozen post-resolution observations.
- Persistent coarse-step autonomy for dismissed recruits, including
  perception-limited sightings and bounded event history.
- Audio Pack V1 for semantic packaged cues without executable playback
  callbacks, AI generation, TTS, or arbitrary media access.
- A source-independent Moddable Core fixture proving the public contracts can
  compose without private runtime reach-through.

## Changed

- Ghost pilgrimage is the conservative built-in default recovery mode.
  Regenerate and owned Recovery Mode V1 profiles remain available.
- Automatic combat events can use readable, fast, or instant presentation
  pacing. Wall-clock delays never affect deterministic order, simulation
  time, saves, or immediate player commands.
- Finite merchants stay depleted. Designed merchants may declare bounded
  authored restock intervals.
- Structure requirements use the shared bounded action resolver instead of
  granting modules tile or structure mutation authority.
- Contributed mobile combat actions use one compact disclosure whose bounded
  menu opens above the fixed dock.
- Downloaded `file://` play exposes compatible HTTPS REST provider profiles
  with an explicit opaque-origin CORS warning rather than a blanket gate.
- Native hosts may expose a host-owned settings window without granting mods
  Electron, peer-control, or arbitrary host authority.

## Fixed and hardened

- Post-commit module outcomes are deeply frozen, serializable, and scrubbed of
  credential-like fields. Observation hooks cannot veto or mutate resolution.
- Module unload removes active owned definitions, restraints, media leases,
  and uncommitted runtime state without rewriting committed history.
- Materialized world tiles remain pinned when a biome recipe disappears; an
  enabled recipe cannot reroll already known geography.
- Combat pacing timers are transient and excluded from the save DTO.
- Group and single-actor mobile combat controls remain reachable across the
  maintained viewport matrix.
- Mods receive no generic callback, DOM, filesystem, provider-credential, or
  raw host escape hatch through the new contracts.

## Compatibility

- Save Schema remains `11`. Existing 0.10.x through 0.16.0 saves load through
  maintained additive migrations; recorded generator versions do not change.
- Module API remains `1`. Existing permissions, package envelopes, and
  minimum-version declarations remain valid.
- Modules using the new Action Profile, Status Effect, Restraint,
  Equipment Definition, Body Profile, Biome Recipe, or Audio Pack contracts
  must require game version `0.18.0` or newer.
- Existing trusted-local callback-era action variants remain compatible but
  are not expanded as the primary authoring model.
- Existing worlds keep their materialized sparse geography. The V1 recipe
  prototype does not rewrite generator identity or claim a complete
  `mapModsHash` solution.

## Known issues and deliberate exclusions

- This candidate is for a select playtest group, not general public release.
- Regional population, persistent supply simulation, designed regions,
  placeable anomalies, and portal worlds remain deferred.
- Permanent body-stat penalties, shrine economies, crafting, Sleep or Rest
  V2, terrain tactics, and reaction priority remain deferred.
- Shared elemental damage/resistance semantics remain module-contract backlog;
  elemental identity stays descriptive.
- AI or TTS audio, additional media providers, physical-device comfort,
  authored-art review, and human translation review remain later work.
- Provider-backed narration and companion decisions remain optional. Offline
  deterministic gameplay does not depend on them.
