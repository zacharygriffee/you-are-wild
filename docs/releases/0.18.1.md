# You Are Wild 0.18.1

Status: **candidate — not published**

Channel: **alpha — select playtest group**

Release date: **operator-gated**

This patch candidate stabilizes the 0.18.0 Moddable Core V1 boundary. It does
not add permissions, saved schemas, resolver effect types, simulation systems,
or new content authority.

## Fixed and hardened

- Fight now opens the same bounded approach chooser used by Feast. This keeps
  actor → target → approach selection consistent across desktop and mobile.
- In Mature posture, Talk and Play expose their named approaches in that same
  chooser; SFW keeps the broad neutral Talk and Play defaults.
- Dance keeps the Talk resolver’s mechanics while preserving dance-specific
  narration, including coordinated combat narration.
- Mature group Talk now carries an explicit Seduce approach through its shared
  delayed command; it resolves as narration instead of an invalid-move error.
- Feed is consistently a support family in group combat: its selected party
  target is preserved through planning and resolution, and it no longer falls
  through to the retired hostile force-feed behavior.
- Selected Fight techniques retain their damage, status, and named narration
  when used from exploration as well as combat.
- AI-assisted companion behavior is visibly unavailable without a registered
  controller. A saved or in-flight AI-assisted choice instead uses deterministic
  Autonomous behavior and narrates that fallback.
- Autonomous restorative Feed/Tend candidates reject hostile targets even if a
  stale reference temporarily appears in party state.
- Invalid combat and group-participant states continue to resolve through
  narration rather than error text or dead-end controls.
- Invalid exploration commands now receive the same in-world narrated feedback
  and failure Scene Feed outcome.

## Compatibility

- Save Schema remains `11`; Module API remains `1`.
- Existing 0.10.x through 0.18.0 saves remain within the maintained additive
  migration contract.
- The Moddable Core V1 compatibility floor remains `0.18.0`; this patch does
  not require a module author to raise an otherwise valid minimum version.

## Deliberate exclusions

This patch does not implement regional populations, persistent merchant supply,
designed regions, anomalies, portal worlds, permanent body-stat penalties,
shrine economies, medical systems, crafting, Sleep or Rest V2, terrain tactics,
or shared elemental damage semantics. Those require their own approved design
and evidence.
