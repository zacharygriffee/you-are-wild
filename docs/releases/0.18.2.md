# You Are Wild 0.18.2

Status: **released public-access alpha**

Channel: **alpha — publicly accessible, intentionally unadvertised**

Release date: **2026-08-04**

This small patch makes the existing interaction and companion-management work easier to test without changing Save Schema 11, Module API 1, module permissions, resolver effects, or simulation authority.

## Added

- Alpha Lab is available from the title screen and in-game menu.
- Eight isolated missions cover single and group interactions, self-containment, combat planning, narrated failures, companion management, content posture, and responsive layout.
- Alpha reports remain local until a tester explicitly copies them or opens a GitHub issue. Reports include bounded Scene context and exact build identity for reproduction.
- Stable `alphaScenario` URLs launch deterministic fixtures for browser agents and human reproduction steps.
- The maintained Alpha browser matrix checks every fixture plus the public mobile mission/report flow in CI.

## Changed

- Fight, Talk, Eat, Play, and Feed use the canonical interaction and sub-action presentation across exploration, combat, single actors, groups, and self-selection.
- Party Holdings supports bounded companion renaming and shared-Pack loadout management without changing stable companion identity or save references.

## Compatibility

- Save Schema remains `11`; Module API remains `1`.
- Existing 0.10.x through 0.18.1 saves remain within the maintained additive migration contract.
- The Moddable Core V1 compatibility floor remains `0.18.0`.
- Alpha fixtures use separate save and world databases and cannot replace an ordinary adventure.

## Deliberate exclusions

The Alpha Lab broadens repeatable testing, not game mechanics. Regional populations, persistent merchant supply, designed regions, anomalies, portal worlds, permanent body-stat penalties, shrine economies, crafting, Sleep or Rest V2, terrain tactics, and shared elemental damage semantics remain deferred.
