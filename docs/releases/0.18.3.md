# You Are Wild 0.18.3

Status: **released select-group alpha**

Channel: **alpha — publicly accessible, intentionally unadvertised**

Release date: **2026-08-10**

This release establishes a clear license boundary, completes the first
backend-neutral Canvas terrain presentation, and carries narrow alpha
stabilization fixes without changing Save Schema 11 or Module API 1.

## Changed

- Releases `v0.18.2` and earlier remain licensed under MIT.
- Releases `v0.18.3` and later use PolyForm Noncommercial 1.0.0.
- The annotated `v0.18.2` Git tag identifies the final MIT-licensed revision.
- Independently authored mods may license their original work separately;
  copied game material keeps the license of the game version it came from.
- Standalone builds, package metadata, README guidance, and regression tests
  disclose and verify the same boundary.
- Mixed-reach group combat now keeps player-actor narration localized instead
  of leaking the English `You` fallback into Spanish Scene prose.
- Missing or vanished group targets now resolve as narrated lost openings that
  name the selected actors, rather than writing a UI instruction into Scene.
- Agent-led ordinary-adventure, interaction-tree, persistence, responsive, and
  Alpha fixture testing is an explicit stabilization gate.
- The release gate now includes a maintained ordinary-adventure lifecycle that
  crosses desktop and phone viewports, two real save/reload boundaries,
  companion management, content posture, active combat, fear/terror,
  containment, narrated failure, Digest, and Release.
- The post-stabilization 3x3 art direction is recorded as a layered semantic
  roadmap covering directional elevation, seamless bridges, compositional
  terrain, persistent world evidence, and future renderer adapters.
- Tile Composition V2 now gives generated terrain deterministic shared seams,
  one shoreline authority, bounded decorative spill, canonical layer order,
  denser jungle identity, and artifact-budget gates across local and hosted
  map surfaces.
- Settings includes No Enemies for uninterrupted map surveying, and the cheat
  surface now keeps Instant Win, God Mode, Never Hungry, Eat Anything, and
  Overpowered behavior aligned with their visible labels.
- Local terrain and Survey share one Canvas2D camera over a deterministic
  backend-neutral Terrain Scene, with continuous biome, shoreline, relief,
  route, bridge, structure, evidence, and party layers.
- Fixed world-space chunks preserve warm movement performance while a bounded
  visual-change journal refreshes off-current features and apron-dependent
  neighboring chunks without conflating rendering with persistence state.
- The ordinary Map command preserves Review Map filters, quest routes,
  markers, inspector, legend, zoom, and pan; Survey remains the explicit
  nearby-terrain camera.
- Remains and depleted resource sites remain visible evidence in Canvas, and
  leaving the Alpha terrain workbench clears its test-only quality and relief
  parameters.

The accepted evidence and continuing release checks are recorded in
`release-readiness-0.18.3.md`.

## Compatibility

- Save Schema remains `11`; Module API remains `1`.
- Existing 0.10.x through 0.18.2 saves remain within the maintained additive
  migration contract.
- The Moddable Core V1 compatibility floor remains `0.18.0`.
