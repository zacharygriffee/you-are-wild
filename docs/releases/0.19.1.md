# You Are Wild 0.19.1 — Internal improvements

Status: **published select-group alpha release**

Release date: 2026-09-09. The operator authorized publishing this maintenance update. The published package preserves the existing alpha audience.

Play: https://you-are-wild-game.zacharygriffee.chatgpt.site
Changelog and poster: https://you-are-wild-game.zacharygriffee.chatgpt.site/changelog#0.19.1

## Added

- Explicit Main Menu routes from Character Creation and the live-game menu; leaving play waits for pending saves and refreshes Continue availability.

## Changed

- Companion Play/Pause controls appear only during combat; exploration cards still show autonomy status.
- Compact desktop companion controls stay on one row above card information, with coordinated mobile combat-tray and roster clearance.
- The playable artifact uses system fonts instead of requesting external fonts, improving self-contained offline behavior.

## Fixed

- Completed adventure interactions are checkpointed so their state and consequences survive Continue and reload.
- Immediate save flushing waits for in-flight saves and follow-up changes before leaving play.
- Marked-target Play no longer offers a duplicate Self route that can replace the intended recipient; valid self-Tend remains available.
- Sparse and full save preparation preserve the chosen actors; unavailable or mixed invalid selections stay blocked for correction instead of silently switching to the player.
- Regression coverage now detects unfinished unit suites and exercises saving, Continue, action selection, and companion-card geometry.

## Known limits

- This select-group alpha is publicly accessible but intentionally unadvertised; broader promotion remains deferred.
- Combat Agency V1 reserves an ordinary future player turn; true reaction priority and emergency out-of-turn player Flee remain deferred.
- Companion Bond V1 does not yet model loyalty decay, needs, neglect, witnessed conduct, desertion, or hostility.
- Physical-device comfort and human review of English and Spanish player-facing copy remain operator observations.
- Provider-backed companion control and AI narration remain optional and depend on endpoint availability; deterministic play does not.

## Compatibility

Existing 0.10.x through 0.19.0 saves load through the maintained additive migrations. Save Schema remains 11; this maintenance release requires no manual migration.
Module API remains 1. Existing minimum-version declarations stay valid; no module permission, callback, or compatibility floor changes.

The recovered companion and witnessed-hostility proposals remain deferred. Terrain backlog and the native desktop-host package are separate work.
